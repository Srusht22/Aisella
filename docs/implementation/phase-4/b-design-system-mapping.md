# B. Design-system mapping (Phase 2 → code)

The source of truth is [Phase 2](../../design/phase-2/README.md). This document says where each part lives in code, and records where the implementation differs from the spec and why.

## 1. Tokens

| Phase 2 | Code | Notes |
|---|---|---|
| `tokens/aisellia-tokens.json` | `lib/design_system/tokens/tokens.g.dart` | Generated by `dart run tool/gen_tokens.dart`; `--check` exits 1 when the file is stale. **Do not edit by hand.** |
| Colour roles, light and dark | `AiselliaPalette` (a `ThemeExtension` with `.light` and `.dark`, and `lerp` for animated theme changes) | Read with `context.palette` |
| Spacing, radii, strokes | `Space.s0…s64`, `Radii.sm/md/lg/full`, `Strokes` | Static constants rather than ThemeExtensions: they never vary by theme, so constants are cheaper and `const`-friendly |
| Layout (breakpoints, gutters, max widths, touch target) | `LayoutTokens` | Used by `WindowClass` and `ContentWidth` |
| Sizes (icons, thumbnails) | `Sizes` | |
| Type scale per script | `TypeScaleTokens.*En` and `*Ckb` → `AppTypography` | The script is chosen from the locale (`scriptFor`) |
| Motion durations, curves, spring, stagger | `MotionTokens` | |

**Deviation (minor):** Phase 3 §11 lists separate ThemeExtensions (Pencil, Semantic, Provenance, Spacing, Radii, Motion, TypeScale). The implementation uses two:
- `AiselliaPalette`, which holds every colour role, including pencil, semantic and provenance;
- `AppTypography`.

Non-colour tokens are constants. The behaviour is the same with less boilerplate.

## 2. Theme and typography

- `buildAppTheme({brightness, locale})` builds `ThemeData` from the palette:
  - the ColorScheme and both extensions;
  - no ink splash (`NoSplash`), with a 6%/10% highlight overlay;
  - app bar, dialog, bottom sheet, snackbar, tooltip and text-selection themes;
  - predictive-back page transitions on Android and Cupertino transitions on iOS;
  - `actionIconTheme` mapping the back and close glyphs to Phosphor.
- Fonts are bundled, never fetched:
  - **Inter** for Latin;
  - **Vazirmatn NL** as the fallback for Arabic script (the "NL" build has no Latin, so mixed strings use Inter for Latin runs);
  - all OFL; licences are registered with `LicenseRegistry` and shown on the Licences page.
- Sorani styles never use letter-spacing or uppercase. `AppTypography.overlineText()` uppercases Latin text only. This is tested.
- Numbers use tabular figures (`numericBody`, `numericTotal`, `numericMetric`).
- Icons: a vendored **Phosphor** subset (57 glyphs, Regular and Fill, about 15 KB each, MIT), produced by `tool/icons/subset_phosphor.py`. Directional glyphs set `matchTextDirection` and mirror in RTL: caret, arrow, u-turn and sign-out. Object glyphs do not mirror. `uses-material-design` is `false`, and a test asserts that no reachable screen renders a Material or Cupertino icon.

## 4. Patterns

Phase 3 proposed a separate `design_system/patterns/` folder. The P-LOAD, P-EMPTY and P-ERR patterns are implemented as the `Skeleton`, `EmptyState` and `ErrorState` components in `components/feedback.dart`, and screens compose them directly. P-OFFLINE is not implemented because there is no network yet. A `patterns/` folder will be added when offline and refresh wrappers are needed (Phase 5).

## 5. Motion (Phase 2 §06)

| Phase 2 | Code | Reduced motion |
|---|---|---|
| Single reduced-motion source | `MotionScope` (app setting) OR `MediaQuery.disableAnimations` (OS) → `Motion.reduced(context)` | — |
| Page transitions | Platform transitions (predictive back on Android) | OS-controlled |
| Press feedback | `PressScale` (1 → 0.98) | Disabled |
| Content entry | `FadeSlideIn` | Fade only |
| Expand / collapse | `ExpandSection` | Instant |
| Number roll (counts, money) | `NumberRoll`: direction-aware; crossfades above 6 digits | Instant swap, with no outgoing frame (tested) |
| Ink settle (§4.1, approval success) | `PencilBox(settled:)` animates the dash gap closed | Instant. **Only triggered in the gallery preview**, because nothing can be approved in Phase 4. Interruption is safe (tested) |
| Skeleton pulse | `Skeleton` | Static |
| Sheets and dialogs | `sheetAnimationStyle` / Material dialog | Shortened |

Durations and curves come only from `MotionTokens`.
